# AB Veterinary Job

A veterinary roleplay resource for RedM, developed for VORP Core by AllieBabyDev.

## Overview

AB Veterinary Job provides an animal care role for servers looking to expand their civilian job opportunities. It includes a custom interface, veterinary assignments, and configurable job settings.

## Features

- Veterinary duty management
- Animal care assignments
- Custom user interface
- Configurable locations and payments
- Built-in debugging options

## Requirements

- RedM
- VORP Core
- Any additional dependencies specified with the release

## Installation

Follow the installation instructions included with your version. Configure the resource for your server before use and start the required dependencies first.
