# 🩺 VORP Veterinarian Job  
**Creator:** AllyBabyDev  
**Framework:** VORP Core  
**Status:** In Development

A fully custom veterinarian job for RedM that allows players to treat injured animals, respond to random emergencies, and revive horses using item-based mechanics and immersive UI.

## ✨ Features (Planned & In Progress)
- Random injured animal alerts
- Player created emergency calls (dead horses, wounded animals)
- Inventory based healing items
- Revival mechanic with progress bars
- Cleanup tasks & XP progression
- Custom UI notifications
- Configurable locations, payouts, and cooldowns

_No server/client code is included in this repo._
